# План реализации Immersive Landscapes — состояние 11 ноября 2026

Текущий выпуск: **IL0.6.0 / DHdormyu.18 / Zoom2**, Horizon f42ef42.
[Этапы M1–M4](completion-milestones.ru.md) и [поставка с доказательствами](renderer-dormyu.18.md).

Генератор0.6.0 завершил ограниченные проверки русел/берегов и переходов окружения;
его байты не менялись в этом обновлении. DH18 исправляет потерю водорослей и
освещения на воспроизведённом стыке. Проверены реальные изображения16/8 и32/16,
повторный процесс, два Rust-клиента, установка, Prism, публикация и скачанные архивы.
Не повторять закрытые этапы без нового кода, дефекта или требования.

Отдельные оставшиеся улучшения: более широкое смешивание океанских оттенков,
дальние приближения рельефа/растительности и другие режимы освещения. Это не
неисправленный прежний шов и не доказательство идеального рендера во всех сценах.
Эстетическое одобрение владельцем этого конкретного клиента ещё не получено.

Performance-тесты явно отменены владельцем. Сохранять native32/DH128 Medium,
sim8/maxFps260/VSync off/nativeLOD0/Auto; не выдавать capture cap за замерFPS.
Новый мир нужен для другой географии, но не для этого DH-исправления.
Будущие структуры используют сохранённый рецепт конкретного мира; деревни,
классы и системы большой сборки не входят в выполненную renderer-задачу.

Все файлы/кэш/миры наE:, один Cargo job, без параллельных тяжёлых сборок.
Teams и остальные приложения пользователя сохранять. Подробная история
реализации остаётся в git и versioned validation0.6.0/DH17/DH18.
