# Продолжение Immersive Landscapes

2026-11-02, автор dormyu, https://github.com/dormyu/immersive-landscapes.

## Что пользователь теперь хочет

Minecraft-масштаб для фэнтези-выживания: разнообразные биомы, связные хребты,
предгорья и природные реки, постепенные переходы. Весьv3 отвергнут: голый
ландшафт, один биом, одиночные огромные горы, сломанный дальний вид.
Не возвращать усиление высоты×4 и не разрабатывать survival-системы.

## Текущая реализация

`0.2.0-dev.1`, descriptor4. Полный MIT-пресет Epic Terrain wonderfulaichen
08507bd3d606ad440b40a5fa726e0098d7309347 адаптирован к родному генератору
Horizon c9d474d /26.3. Сохраняются все88 registry JSON, деревья, пещеры, руды,
структуры, биомы и исходная геометрия. В базовых шумах температуры/влажности
xz_scale0.2→0.8, чтобы климатические области были компактнее.

Native prepare HEAD устанавливает полный рецепт в новый обычный мир ДО
загрузки регистров. Это работает и в dedicated Rust-сервере. Существующие
vanilla saves пропускаются; descriptor4 сохраняет свой рецепт. Мирыv1–v3
открываются только архивными билдами, без молчаливого изменения генератора.
Внешний preset `<game>/horizon-mods/immersive-landscapes-preset` копируется
только в новые миры. Никакого ручного datapack или подготовленного мира.

Активные файлы bundle: horizon-mixin.toml, preset_adapter.rs, prepare.rs,
list.rs и создаваемый tools/native.py файл preset.generated.rs.
Старые ChunkGenerator/LevelShape/spawn hooks удалены. Rust-library подsrc
сохранена как исследование, она не управляет нынешними чанками.
v3 сохранён локально: archive/rejected-v3-20261102,72b2a41.
